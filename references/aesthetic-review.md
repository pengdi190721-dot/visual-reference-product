# 审美决策与反证验收

“资深艺术总监、精致、高级、日系”只能提供方向，不能替代选择。审美提升靠参考证据、素材适配、主次取舍和实际看图，而不是越长的形容词越有效。

## 用喜欢与不喜欢的图片校准

用户给过满意样图和失败图时，记录喜欢的可见关系及不喜欢的具体问题。不要将某张满意图的所有元素复制成固定模板。漂亮样图中的未核实性能、品牌刊头和产品参数仍不能照抄。默认先做好看的完整方案；需要额外详情而资料不足时，允许按 [详情来源规范](detail-provenance.md) 创意补图并在出图后明确核对。

每次识别最能决定本图气质的关键特征，用户明确要求和圈出的细节另逐项保留；不能因追求“少量”而丢项。例如生活化的动作、主图与标题的互动、自然光影、主次图之间的节奏。仅换背景色、纸张纹理、手写字体或页码，不足以证明参考风格落实。

## 内部比较，再选一个方向执行

在任务文件里提出两个真正不同的构图候选，简短描述即可；不要求用户选、不默认额外付费出两张，也不强制调用绘图工具。

对有全身人物和手持产品的页面，可以比较：

- 保留自然场景与全身动作，主标题借用真实留白，人体落地关系完整。
- 保留产品与上身互动，采用大半身主图和错落标题；辅助信息减少，以主体为中心形成阅读路线。

这只是比较方式的示例，不是固定两套模板。根据产品、素材、用途和参考确定候选。写出选择理由及放弃另一方案的原因，不能只比较两种字体或两种底色。

## 先解决结构，再做装饰

1. **素材适配**：目标商品是谁；哪些真实角度最能展示；动作是否自然；是否需要抠图；现有姿态能否放进该页面。
2. **视觉骨架**：确定首要焦点和第二落点，让人物、产品、标题形成关系。大面积留白应有平衡和用途，不能只把左右两列各摆一堆。
3. **阅读与密度**：用途决定正文量。手机上需要读的内容按手机尺寸检查；原尺寸清楚但缩小不可读时，减少次要信息、放大或拆页，不把大量微型正文当杂志感。
4. **字形和节奏**：执行中文规范；手写体不自动等于轻盈。逐字加空格、过大的字距、机械对齐的两行、过多相同粗细的横线都可能让画面生硬。
5. **装饰组织**：在蓝图阶段就安排用户指定的气泡、手绘和跳色，与主图一起构成完整第一稿；最后微调位置和密度。用户未要求的装饰按作用取舍，明确要求的不能自行删除或固定上限。不得把虚构期号或大牌刊头包装成真实杂志出版信息。

## 成图反证：寻找最不成立的一处

先不看自己的提示词和设计说明，只看实际图，再与原图及参考对照。若宿主无法实际看图，不能靠自述完成验收。

| 要回答的问题 | 需要的证据 | 不充分的理由 |
| --- | --- | --- |
| 第一眼看到什么，是否符合任务 | 标出首要焦点、第二落点和明显竞争项 | “字号层级齐全” |
| 主体是否自然地存在于画面中 | 身体重心、落地或刻意腾空逻辑、光影和轮廓 | “直接贴了原图” |
| 中文为何适合这个产品 | 字面密度、语义断行、文字色与主图关系 | “用了手写体，所以高级” |
| 这一页为何像选定参考 | 逐条指出关键风格在成图的位置 | “米白纸纹加页码” |
| 手机上必要信息能否读清 | 实际缩略视图与无法读清的内容 | “原图正文是清晰字体” |
| 丰富度是否符合用户，哪些位置需要重排 | 对照需求看气泡、手绘、细节和主图的疏密关系；不删除用户要的元素来规避排版 | “越少越高级”或“越多越好看” |

不强制打总分，不编造美观百分比。允许整体漂亮而局部有问题，但不能把有明显残边、无意裁脚、产品身份未确认等问题的图片判为成品通过。确实没有发现问题时写清检查范围，不能为了“反思”编造错误。

## 可直接放进实际设计任务的审美约束

> 先根据参考与真实素材选择适合的构图，再制作完整页面。产品、人物和中文标题必须形成清楚的主次与互动，不默认左文右图，不靠纸纹、页码或贴纸堆出杂志感。中文按语义断行，选择匹配主题的字形和重量，保证手机观看时必要信息可读。人物保持自然重心；全身构图完整保留脚尖并留出合理空间，半身构图采用自然裁切，不在关节处硬切。抠图先处理残底、白边、细杆与真实空隙，再做合成；不要用扩边、重影或大光晕掩盖缺陷。完成后实际看整图、手机缩略图和关键局部，指出最影响效果的问题；存在明显硬伤就修订或标为未完成，不因为使用原图或手写体就判通过。

这段是检查与设计约束，不是质量保证。按本图选择有关部分压入提示词，完整规范留在本地供验收使用。

## 丰富图文第一稿：迁移关系，不只凑组件

用户偏好丰富生活感时，蓝图先回答：主人物怎样与产品互动；场景光线怎样形成空间；主标题与主体怎样交叠呼应；辅助照片怎样改变景别；详情怎样提供不同信息；气泡与手绘怎样把视线带回主体。按本次证据选择，没有人物需求不强加人物。

不要把这种参考等价替换为“俯拍商品占右上、人物证件照占左边、下方三等分细节、整齐参数表”。即使组件数相同，情绪、空间和阅读节奏也可能完全不同。缺少真实互动素材时，已允许视觉创作就可通过美图制作待核实场景，保留已知外观并标来源；不能只因手里没有完全相同姿势，就偷偷降低设计目标。

手机缩略图先看整体：若仍像整齐商品目录，再加两个爱心不会解决问题。先调整主场景、焦点比例、摄影视角、光影与前后层次，再微调装饰。已确认准确文案与产品身份始终保留。
