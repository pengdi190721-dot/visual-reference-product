# 成图一致性检查

先打开实际成图，再进行验收。工具说生成成功只代表任务状态，不代表画质或一致性通过。无法查看时保留“待视觉验收”。

## 三栏对照

每一项同时写出原依据、成图区域、结论。结果用「通过 / 不通过 / 未能验证 / 不适用」，不能以总分掩盖硬伤。

| 检查 | 对照项目 | 失败处理 |
| --- | --- | --- |
| 产品身份 | 外轮廓、部件数量、结构、开合关系、标志/货号 | 不通过，优先修复 |
| 外观还原 | 配色、图案位置、面料外观、比例、五金与细节 | 区分照明变化与真实改色 |
| 人物一致 | 指定人物的五官关系、发型、明显特征、体态 | 无指定人物则不适用 |
| 物理合理 | 手指、抓握、遮挡、接触阴影、穿戴与物品尺寸关系 | 结构/穿戴错误不通过 |
| 文案准确 | 主标题、品牌、货号、事实文案逐字核对 | 关键错字或新增承诺不通过 |
| 中文排版 | 字形、笔画重量、语义断行、间隔、层级、对比、文字与主体的关系 | 粗重失衡、难读或照搬英文导致拥挤不通过；字对不等于版对 |
| 风格迁移 | 对照蓝图中必须保留的特征：布局、留白、光线、色彩、文字 | 关键特征丢失不通过，指出实际落点；只改背景色不算充分迁移 |
| 页面完整 | 约定的页面类型、必要文字、主辅内容、阅读顺序 | 完整页只完成底图或只补字未完成设计，不通过并注明未完成阶段 |
| 输出规格 | 比例、清晰度、数量、是否误生成样机或拼图 | 不符合要求则不通过 |

看不见的伞骨、包背面、衣服后片不能给通过；在报告写“未展示，无法核验”。缺原图的概念图不能获得真实产品一致性通过。

无需声称精确一致率：人工看图不能证明像素级、真实尺寸、材料成分、认证或性能。已知的隐藏参数只能检查文案有没有乱写，不能通过图片证明物理事实。

整页缩到手机观看尺寸检查视觉焦点、文字重量和阅读顺序，再用原尺寸检查中文与产品细节。具体按 [中文排版规范](chinese-typography.md)。不能凭提示词里有“精致”“手写”就判成图具有这些特征。审美判断写出可见理由，不伪造客观美观百分比。

整体通过要求：所有适用的硬约束、必须保留的设计特征和页面完成项均已检查通过，且没有尚未解决的失败项。可选装饰的轻微差异可注明接受；未知且本来不展示的产品背面等不属于本图必验项，明确范围即可。必要项无法验证时结论待验收，不用“基本可用”含糊带过。

## 修订策略与问题继承

先解决产品结构与指定人物等硬伤，再修文字和版式；修复顺序不代表风格要求可以放弃。一次修订聚焦明确失败项，保留已经通过的约束。把修订计划回写提示词与检查记录。

每个问题分配编号，记录发现版本、成图区域、预期行为、修复动作、当前状态与新图证据。进入下一版时继承所有未关闭问题。只改文字时，原来的印花缺失、手部错误、比例异常仍待复核；没有在新图中实际检查就不能自动关闭。新一版仍要复查产品、人物、全部必要文字与关键设计，防止改好标题却换了产品。

画面漂亮但产品变款时不要交付为合格成品；可展示并注明问题。反复失败时建议更清晰/多角度产品图、降低遮挡或调整实现方式；若减少文字、改简洁构图会丢失约定设计，须向用户说明取舍，不能静默降级。在用户已授权的尝试数内执行，不以“优化”为名无上限扣费。没有授权重试时照实交付失败样稿、问题清单和修订方案。
