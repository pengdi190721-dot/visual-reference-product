# 无需口令的自动引导

这份模板给助手使用，不是让学员复制的提示词。话术按实际素材调整，不照抄不存在的张数、风格或已完成状态。

## 学员视角

| 学员做什么 | 助手接着做什么 |
| --- | --- |
| 只上传一张或多张对标图，一句话不说 | “我先逐张看这组图，拆出构图、配色、光影和排版，再归类它们的风格。”随后实际解析，不停在承诺 |
| 无需再补一句“开始” | 展示简短逐图结论与分组；完整证据单独保存，然后说：“接下来把你自己的产品照片发来，正面清楚的一张就能开始。” |
| 只上传自己的产品图 | “产品图收到了。我会保留图里能看清的外形、颜色和细节。你知道的名称、尺寸、材质、特点，以及想放的文字补充一下就行；不知道就说‘不知道’，我按图片来设计。”删掉已知或无关问题 |
| 回答参数，或只说“不知道” | 进入精准或视觉创作模式；展示 4—6 行摘要，不再追问同一组参数 |
| 已说“直接生成”或此时回“生成” | 调用 LibTV，等待并查看实际成图，完成产品/人物一致性检查 |

用户只说“不知道”而没要求生成时，先给摘要，末尾用一句“想按这个方向出图，回我‘生成’就行。”这只是在确认实际生图意图，不是新的使用口令门槛。任何含义相同的自然回复都接受。

## 当前任务状态记录

保存为任务目录中的 `流程状态.md`，持续更新，不能保存到技能安装目录。

- 当前阶段：解析对标 / 等待产品 / 收集参数 / 创意就绪 / 已提交生成 / 验收交付。
- 已收到的对标图：编号、文件、是否实际看过、是否重复。
- 待解析图：编号与原因。
- 已建立风格组：编号与成员。
- 产品图：编号与角色依据（例如“等待产品后的上传”或用户明确说明）。
- 指定人物图：编号及用户要求；未指定则无。
- 产品问卷：尚未问 / 已问待回复 / 已答 / 用户跳过。
- 已知事实、未知项和锁定清单：链接产品档案。
- 是否已展示本版摘要：是/否。
- 页面蓝图：约定页面类型、关键风格特征、中文排版方案和文件位置；内部记录，不要求学员填写。
- 本版完成阶段：完整页 / 底图 / 待排字 / 待验收；未完成不能写成已交付成品。
- 上版未解决问题：编号与验收记录位置；修订必须继承。
- 用户生图原话与约定张数：没有则留空，不能由“上传了图”推断。
- LibTV 原节点及本地运行目录：尚未调用则留空。
- 下一步：只记录当前最必要的一步。

## 接续原则

- 首批一张图也启动分析；分批发来就增量解析，不强制等齐、不反复分析未变化的图片。
- 初次输入只有图片，不先问“这些是什么用途”；已有明确的截图答疑、识字等其他任务时不抢流程。
- 用户更正角色，保留旧记录的更正说明，迁移相应素材到正确角色并更新锁定与分组。
- 对标与产品混合上传且用户没有任何说明，首批先按对标处理，解析后邀请产品；用户指出某张是产品后再更正，不自行猜“最后一张”。
- 上下文丢失时先读取任务状态与已有档案；不要求学员重说整段流程。
- 用户说只分析/只写提示词时停在对应交付，不强推产品上传或生图。
