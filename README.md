# 灵感映像｜对标生图助手

**先上传对标图，一句话不说也能开始。先做好看的完整视觉方案，再核对缺少实拍依据的细节。**

版本：0.5.0。适合 WorkBuddy 与兼容技能文件、能看图和执行本地命令的宿主。支持多种风格，不固定成日系。

## 本版改了什么

- **需求逐项保留**：把输出张数、产品事实、关键风格、圈选细节与待修问题放在同一份当前清单。修改时保留上一版，新旧要求不再混在一起。
- **提交前检查**：美图调用计划必须关联清单。漏掉依赖参考、需求落实方法或问题收口依据时停止；有效需求自动附入实际提示词。
- **交付前检查**：要求三页就核对三页；每项需求都要有实际看图证据。关键设计未通过不能说“可以直接用”，旧图片的验收不能套到新图上。
- **第一稿保留丰富度**：用户喜欢的人物互动、空间光影、细节图、气泡和可爱手绘，一开始一起设计。不能自己改成极简，再等学员逐个提醒。
- **少问重复问题**：选择版式不等于跳过产品参数；已确认参数不再问；已选择先出完整方案，就在授权范围内继续完成。
- **保留现有能力**：美图设计室、中文排版、抠图与脚部检查、先出美观草稿再核对详情，继续有效。

这些内部记录由助手完成，学员仍只需上传图片、回答已知信息和看图。脚本不替代视觉判断，也无法阻止宿主绕过技能直接操作，不能保证永不遗漏。

## 下载与安装

[下载 0.5.0 完整安装包](https://github.com/pengdi190721-dot/visual-reference-product/releases/download/v0.5.0/visual-reference-product-0.5.0.zip)。

在 WorkBuddy「专家·技能·连接器」→「技能」→「添加技能」→「上传技能」导入完整包，入口以实际界面为准。新版仍由使用者自行安装，本包不会自动修改已有副本。

升级前备份自行修改过的技能内容，使用可用的替换入口；若不支持完整替换，移除旧技能后导入新版。**不要仅覆盖几个文件，以免留下旧生图脚本；不要同时启用新旧同名技能。** 学员任务与素材保留在独立任务目录，不随技能升级删除。

安装包排除 `.gitignore`，许可证使用 `LICENSE.md`。请下载上面的发布附件，不要使用仓库源码压缩包；源码仍含仓库管理文件。不要只上传 `SKILL.md` 而遗漏配套规范。

也可从解压目录运行：

```sh
python3 scripts/install.py
python3 scripts/install.py --check
```

脚本默认安装到用户目录 `.workbuddy/skills/visual-reference-product/`，已有目录不覆盖。Windows 可用 `py -3` 替换 `python3`；需要自定义技能目录时用 `--skills-dir`。文件校验通过不代表界面已经启用，安装后新开会话查看技能状态。

## 学员怎么用

| 学员做什么 | 助手接着做什么 |
| --- | --- |
| 先上传喜欢的对标图，可以不说话 | 逐张解析、记录证据和置信度、归类风格，再邀请上传产品 |
| 接着只上传自己的产品图 | 锁定可见外观，集中询问已知参数；有详情图可补，没有也能继续 |
| 补充参数或说“不知道，直接生成” | 给简短摘要，先做完整视觉方案；已有生成意图时不多问一轮 |
| 查看成图 | 同时看到真实资料、裁切细节、创意补图及拟用文案的来源说明 |
| 对照实物确认，或上传不一致部位的照片 | 保留整体设计，替换对应局部或文案，再检查完整页面 |

首批无文字图片默认作对标，不猜最后一张就是产品；等待产品后收到的新图按产品接收。只需要分析可说“只分析”。只传对标图不代表同意上传到美图或扣费。

产品信息可以这样补充，知道多少说多少，不是开工门槛：

> 我的产品是：21寸三折伞，软萌治愈系。尺寸：53*8K；布料：黑胶布；伞架：铁架；包装：OPP；货号：HZZ2607；功能：黑胶防晒，轻巧便利。

**详情图不必提前备齐。** 有真实图就用；原图清晰就裁切；确实缺少的部位可作为创意设想先出视觉稿，再指出“右下收纳图的折叠形态是补出的”等具体位置。符合实物由学员确认保留，不符合再补对应细节图。不能笼统说一句“AI生成”就跳过核对，也不能把未知认证、性能数字随便写成事实。

## 美图能不能精细抠图

美图官方网页编辑器支持智能选区、局部抠图、擦除/恢复和边缘羽化，见 [官方说明](https://www.designkit.cn/help/84)。但当前连接器主要发送自然语言任务，没有单独暴露画笔控制。**功能存在不等于这张图已经能自动精修合格。** 本版会明确请求抠图、检查实际结果；能力不足就交代缺口，不伪称完成。

准备：WorkBuddy 能看到图片；连接「美图设计室 AI设计 CLI」并完成自己的登录；本机有 Python 3.9 以上。官方命令为 `designkit`，来源为 npm 包 `meitu-designkit-cli`，本技能不附带第三方程序、账号或额度。

只读检查：

```sh
python3 scripts/meitu_adapter.py doctor
python3 scripts/meitu_adapter.py doctor --check-auth
```

具体调用、登录和长任务接续见 [美图适配](references/meitu.md)。美图可能消耗美豆；一个任务可能内部执行多步，不将一次提交说成固定一次收费。中断先查原房间，不重复投递付费任务。

## 检查与限制

```sh
python3 -m unittest discover -s tests -v
python3 scripts/check_analysis.py templates/evidence.json
```

测试检查需求继承、输出覆盖、失效验收拦截、实际提示词注入、附件顺序、重复提交保护、来源账本和打包，不证明图片好看。技能自动触发取决于宿主是否加载技能和图片。本版已结合旧版实际 WorkBuddy 对话和成图修正，但尚未在 WorkBuddy 安装新版并完成真实生图全流程验证，不能保证任何复杂发丝或人体图一次成功。

本版允许“完整视觉稿已完成，部分细节待核实”，分别记录视觉质量和事实状态。确认依据保留为用户核对，不冒充第三方检测；原图贴入也要检查裁切、蒙版和变形。

## 发布维护

公开包只含技能、规范、模板、脚本与测试；私人原图、任务记录、凭据和生成物不得入仓库。代码与文档使用 MIT 许可，不代替用户素材的授权。只有用户授权具体仓库后才能推送。

```sh
python3 scripts/package.py --output ../visual-reference-product-0.5.0.zip
```

打包后生成压缩包和逐文件散列清单。不要把美图房间记录或学员素材放入技能目录。

## 原有任务怎样接着做

升级后可继续原任务，助手先根据已有对话恢复最新有效需求，区分“未答”和“主动跳过”，保留原房间与生成结果。旧调用计划是第 2 版，新版是第 3 版，需补上需求清单与输出编号；不要为了迁移重新投递已经提交的任务。

也可给助手这一句，方便续作，但不是学员使用的必需口令：

> 按当前技能继续。先整理我已经确认的要求，保留喜欢的构图、气泡、手绘和详情内容；本轮只修改我指出的问题，完成后逐项核对，别让我重新说一遍。
